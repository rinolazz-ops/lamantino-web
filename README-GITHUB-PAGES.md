# Il Lamantino — file per GitHub Pages

Questa cartella contiene una versione statica del sito. Per pubblicarla, carica **il contenuto** di questa cartella nella radice della tua repository pubblica (in modo che `index.html` sia al livello principale, non dentro una sottocartella `github-pages`). Poi, nelle impostazioni della repository, apri **Settings → Pages**, scegli **Deploy from a branch**, seleziona il branch `main` e la cartella `/(root)`.

I link a CSS, JavaScript e immagine sono relativi, quindi funzionano anche all’indirizzo di un sito di progetto come `utente.github.io/nome-repository/`.

Il pulsante e il modulo di contatto aprono WhatsApp al numero configurato. Il modulo prepara il testo; la persona può rileggerlo e inviarlo da WhatsApp. Il sito non raccoglie né archivia i dati e non invia SMS autonomamente.

`assets/alberto-hero.jpg` è una copia JPEG della foto che hai fornito, usata come immagine principale provvisoria. La copertina illustrata basata sulla foto è ancora in generazione e non è inclusa in questo pacchetto. Quando sarà disponibile, potrai sostituire `assets/alberto-hero.jpg` con quella copertina, mantenendo lo stesso nome file, oppure aggiornare il riferimento in `index.html`.
